### Qualidade do Sinal de Operadoras no Brasil

Projeto para analisar a qualidade de sinal de operadoras (2G/4G) no Brasil com base em dados fornecidos pela Anatel. 

## Objetivo

O Projeto foi realizado para realizar predições e ajudar empresas de telemetria/rastreamento a identificar áreas de risco e locais com pouca disponibilidade de sinal no território brasileiro, visando ajudar na análise de riscos e dores do setor envolvendo a qualidade de sinal e transmissão de dados de localização dos rastreadores/localizadores que utilizam sinal GPRS.
